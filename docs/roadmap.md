# Goldfinch InsureERP — Future Roadmap

Items planned for subsequent release phases:

1. **Real-Time Direct Underwriter API Connectors**
   - Direct quote generation and instant digital certificate retrieval from Britam Bionic, Jubilee API, and CIC portal.

2. **Client Self-Service Portal**
   - Web portal for insured clients to view active policies, download motor digital certificates, initiate claims, and pay via STK push.

3. **Native Mobile Field App**
   - iOS and Android mobile app for agency field sales agents with offline quote generation and photo inspection uploads.

4. **Automated IRA Statutory Return Transmission**
   - Direct system-to-system integration with the Insurance Regulatory Authority (IRA) Online Regulatory Portal.
